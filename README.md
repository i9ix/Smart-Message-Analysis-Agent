Smart Message Analysis Agent

A Python-based AI agent that analyzes text messages locally using Ollama and the Llama 3 language model.

Overview

This project uses a local Large Language Model (LLM) to analyze messages and extract meaningful information.

Features

* Sentiment Analysis: Identifies positive, negative, or neutral sentiment.
* Topic Identification: Extracts the main topic of a message.
* Urgent Request Extraction: Identifies urgent requests or complaints.

Technologies Used

* Python
* Ollama
* Llama 3 (LLM)

Requirements

* Python 3
* Ollama
* Llama 3 model

Installation and Usage

1. Install Ollama

Download Ollama from https://ollama.com/

2. Download the model

Run the following command:

ollama pull llama3

3. Install dependencies

pip install ollama

4. Run the project

python main.py

Make sure Ollama is running before executing the script.

Example

The agent analyzes a message and returns:

* Overall sentiment
* Main topic
* Urgent request or complaint, if any

The output may vary depending on the model’s response.

Limitations

The analysis is generated by an AI model and may not always be accurate. This project does not currently provide dedicated phishing detection.
