# Smart Message Analysis Agent

A local AI tool that analyzes text messages (Arabic-friendly) using Ollama and Llama 3. Everything runs on your machine, so your messages never leave your device.

## Features

- Sentiment analysis (positive / negative / neutral)
- Main topic extraction
- Message category (complaint / inquiry / request / other)
- Urgency score from 1 to 5
- Urgent request extraction
- Structured JSON output

## Requirements

- Python 3
- [Ollama](https://ollama.com/)
- Llama 3 model

## Installation and Usage

1. Install Ollama from https://ollama.com/
2. Download the model:
   ```
   ollama pull llama3
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Make sure Ollama is running, then start the program:
   ```
   python main.py
   ```
5. Type a message and press Enter. Type `exit` to quit.

## Example

Input:

```
عندي مشكلة في حسابي موقف لي كل شيء وانا جدا غاضبه، اتمنى تحلونها بشكل عاجل!!!
```

Output (your result may vary):

```json
{
  "sentiment": "سلبي",
  "topic": "مشكلة في الحساب الشخصي",
  "category": "شكوى",
  "urgency": 5,
  "urgent_request": "حل مشكلة إيقاف الحساب بشكل عاجل"
}
```

## Limitations

- The analysis is generated by an AI model and may not always be accurate.
- Arabic dialect understanding depends on the model used.
- This project does not provide dedicated phishing detection.
